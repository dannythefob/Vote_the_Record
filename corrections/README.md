# Corrections

Found an error? [Submit a correction](CORRECTIONS_FORM_URL).

The project owner reviews every submission. Accepted corrections are added by hand to
[`log.yaml`](log.yaml) and published on the site. Entries are never deleted. Collectors,
scripts, and AI assistants never write to this log.

Each entry records:

| Field | Meaning |
|---|---|
| `date` | Date the correction was made (YYYY-MM-DD) |
| `target` | Full fact or mapping ID that changed |
| `change` | What changed, old and new |
| `reason` | Why |
| `source_url` | Evidence for the correction |
| `reviewer` | Who reviewed it |
