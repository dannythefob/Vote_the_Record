# site/

The public website, generated by `src/build/build.py` from `data/`, `offices/`,
`corrections/`, and `docs/METHODOLOGY.md`.

- `site.yaml`: site settings (beta banner, corrections form URL, official links)
- `templates/`: Jinja2 page templates (autoescaped)
- `static/`: CSS, self-hosted fonts (SIL Open Font License, see `fonts/OFL-*.txt`),
  and `_headers` (Cloudflare Pages security headers, including the CSP)
- `dist/`: build output, not committed

## Build and preview locally

```
.venv/Scripts/pip install -r requirements-dev.txt
.venv/Scripts/python src/build/build.py
.venv/Scripts/python -m http.server 8000 -d site/dist
```

Then open http://localhost:8000.

To see race pages before real races exist, build the fictional demo (never deploy it):

```
.venv/Scripts/python src/build/build.py --root tests/fixtures/demo --out site/dist-demo --demo
.venv/Scripts/python -m http.server 8001 -d site/dist-demo
```

Tests: `python -m pytest tests` runs the Python tests, the JS scoring tests (needs Node),
and a headless-Chrome check of the demo build (needs Chrome or Edge); the last two skip
locally if the tool is missing and are required in CI.

The build stops, writing nothing, if the validator finds any error. Note: `http.server` ignores `_headers`, but every page also carries
the CSP in a `<meta>` tag, so violations still show in the browser console.

## Deploy on Cloudflare Pages

| Setting | Value |
|---|---|
| Framework preset | None |
| Build command | `pip install -r requirements.txt && python src/build/build.py` |
| Build output directory | `site/dist` |
| Root directory | *(blank)* |
| Environment variable | `PYTHON_VERSION` = `3.12` |
| Build system version | v3 |

Keep Cloudflare Web Analytics turned off: it injects a third-party script.

If Cloudflare's build can't run, use the fallback workflow in
`.github/workflows/deploy.yml`, which builds on GitHub Actions and uploads with Wrangler.
